# BLock- Messenger: проектный каркас

Этот репозиторий содержит стартовую архитектуру и эталонные реализации критичных алгоритмов для мессенджера уровня Telegram:

- анонимная регистрация (только Google email + TOTP);
- E2E-шифрование на базе X3DH + Double Ratchet;
- чаты по контактам и username;
- каналы и лента новостей по времени;
- голосовые/видео сообщения, VoIP/видеозвонки, шаринг экрана (архитектурно).

## Что реализовано в коде

1. `backend/security/async_ratchet.py`
   - Упрощённая модель асинхронного обмена ключами и ратчета сообщений.
2. `backend/services/auth.py`
   - Проверка допустимого домена (`gmail.com`, `googlemail.com`) и TOTP (RFC 6238).
3. `backend/services/contact_discovery.py`
   - Приватный поиск контактов через HMAC-индексацию (без передачи «сырых» номеров).
4. `backend/services/news_feed.py`
   - K-way merge ленты каналов с сортировкой по времени публикации.
5. `docs/system_design_ru.md`
   - Детальная документация по архитектуре, безопасности и дорожной карте.
